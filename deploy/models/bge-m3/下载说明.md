# bge-m3 模型存放目录

把下载好的模型文件**直接放在这个目录里**（不要再套一层文件夹），最终结构是这样：

```
deploy/models/bge-m3/
├── config.json
├── pytorch_model.bin        ← 主文件，约 2.11 GB
├── tokenizer.json
├── tokenizer_config.json
├── special_tokens_map.json
├── sentencepiece.bpe.model
├── colbert_linear.pt
├── sparse_linear.pt
├── config_sentence_transformers.json
├── modules.json
├── sentence_bert_config.json
└── 1_Pooling/config.json
```

## 下载源

- 国内（推荐，速度快）：https://modelscope.cn/models/BAAI/bge-m3/files
- 官方：https://huggingface.co/BAAI/bge-m3/tree/main

## 下什么

**下整个仓库即可，唯一可以跳过的是 `onnx/` 目录**（约 2.17 GB，是给 ONNX 推理用的，
本项目走 PyTorch，用不到）。`imgs/`、`*.jpg`、`README.md` 是说明图，可跳过。

核心文件只有 8 个，合计约 2.14 GB：

| 文件 | 大小 | 作用 |
|---|---|---|
| `pytorch_model.bin` | 2.11 GB | 模型权重（必须有） |
| `tokenizer.json` | 16.3 MB | 分词器 |
| `sentencepiece.bpe.model` | 4.8 MB | 分词器（中文） |
| `colbert_linear.pt` | 2.0 MB | ColBERT 头 |
| `sparse_linear.pt` | 3.4 KB | **稀疏向量头，缺了就没有文号精确匹配** |
| `config.json` | 687 B | 模型配置 |
| `tokenizer_config.json` | 444 B | 分词器配置 |
| `special_tokens_map.json` | 964 B | 特殊符号映射 |

## 为什么用本地目录而不是让它自动下载

Embedding 服务默认会去 HuggingFace 自动下载，但本机访问 huggingface.co 会超时。
所以改成挂载本地目录：容器启动时直接读这里的文件，不联网。

## 下完之后

不用自己改配置。告诉开发方"下好了"，剩下的两步是：

1. `.env` 里把 `EMBEDDING_BACKEND=stub` 改成 `bge_m3`，
   并把 `EMBEDDING_MODEL` 指向容器内路径 `/models/bge-m3`；
2. 重建 embedding 镜像（要装 PyTorch，约 1 GB 下载）并重启，然后重建向量索引。

因为向量从"占位哈希"换成了真实语义向量，**现有索引必须整体重建**，
否则新旧两种向量混在同一个集合里，检索结果会乱。
