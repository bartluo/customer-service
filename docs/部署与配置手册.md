# 部署与配置手册

按顺序做下去即可。所有命令都在项目根目录执行（能看到 `docker-compose.yml` 的那一层）。

---

## 开始之前

### 机器要求

| 项目 | 要求 |
|---|---|
| 内存 | 16 GB 以上（建议 32 GB） |
| 可用磁盘 | 40 GB 以上 |
| 操作系统 | Windows 10/11 + WSL2，或 Linux |
| 网络 | 能访问 Docker Hub |

### 需要准备

| 项目 | 说明 |
|---|---|
| Docker Desktop | 免费，自行下载安装 |
| 本项目代码 | 见第二步 |
| bge-m3 模型文件（2.1 GB） | 可跳过，见第五步 |

---

## 第一步：安装 Docker Desktop

1. 打开 <https://www.docker.com/products/docker-desktop/> 下载并安装。
2. 安装过程中提示启用 WSL2 时，选择同意。
3. 安装完成后启动 Docker Desktop，等待任务栏鲸鱼图标停止转圈。

验证：

```powershell
docker compose version
```

显示版本号即完成。以后每次启动系统前，都要先打开 Docker Desktop。

---

## 第二步：下载代码

```powershell
git clone https://github.com/bartluo/customer-service.git
cd customer-service
```

没有 Git 的话，到 <https://github.com/bartluo/customer-service> 点 `Code` → `Download ZIP`，
解压到一个路径中没有中文和空格的位置（例如 `D:\customer-service`），在该目录打开 PowerShell。

---

## 第三步：生成配置文件

```powershell
Copy-Item .env.example .env
```

无任何输出即成功。

---

## 第四步：填写配置

用记事本打开 `.env`，修改以下 5 项：

| 配置项 | 填写内容 |
|---|---|
| `BOOTSTRAP_ADMIN_PASSWORD` | 12 位以上的管理员口令 |
| `JWT_SECRET` | 随机长字符串，40 位左右 |
| `POSTGRES_PASSWORD` | 数据库口令 |
| `S3_SECRET_KEY` | 存储口令 |
| `ENVIRONMENT` | 对外提供服务时填 `production`，内部使用保持 `development` |

生成随机字符串（PowerShell，每运行一次出一个）：

```powershell
-join ((48..57) + (65..90) + (97..122) | Get-Random -Count 40 | ForEach-Object { [char]$_ })
```

另外，把 `S3_SECRET_KEY` 的值同步写入 `deploy/seaweedfs/s3.json` 中 `app` 账号的 `secretKey`，
两处必须一致。

其余配置项保持默认即可。需要调整时查本文最后的配置表。

---

## 第五步：下载模型（可跳过）

跳过时系统仍能启动，但检索结果不准确，只适合验证安装。

要获得正常的检索效果，按 [deploy/models/bge-m3/下载说明.md](../deploy/models/bge-m3/下载说明.md)
把 8 个核心文件放进 `deploy/models/bge-m3/`，然后在 `.env` 中修改：

```ini
EMBEDDING_BACKEND=bge_m3
EMBEDDING_MODEL=/models/bge-m3
```

并在第六步的启动命令之前，先执行：

```powershell
docker compose build --build-arg INSTALL_HEAVY=true embedding
```

---

## 第六步：启动系统

```powershell
docker compose up -d
```

首次执行需要 10～30 分钟，中途不要关闭窗口。

检查状态：

```powershell
docker compose ps
```

应看到 9 个服务：`postgres`、`qdrant`、`redis`、`seaweedfs`、`embedding`、`backend`、
`worker`、`frontend` 处于运行状态，`s3_init` 显示 `Exited (0)`。

执行数据库迁移：

```powershell
docker compose exec -T backend alembic upgrade head
```

---

## 第七步：初始化数据

### 1. 取得管理员口令

第四步中填写了 `BOOTSTRAP_ADMIN_PASSWORD` 时，直接使用该口令。

没有填写时，口令在首次启动时生成并打印一次：

```powershell
docker compose logs backend | Select-String "固定管理员"
```

查不到时，重置口令：

```powershell
docker compose exec backend python /app/scripts/reset_admin_password.py
```

### 2. 安装脚本运行环境

```powershell
python -m venv .venv
.venv\Scripts\python.exe -m pip install -r scripts\requirements.txt
```

需要先安装 Python 3.12，安装时勾选 "Add python.exe to PATH"。

### 3. 导入法规

```powershell
.venv\Scripts\python.exe scripts\import_regulations.py --inbox "法规数据\待导入-小微专题"
```

从官方渠道采集更多法规：

```powershell
.venv\Scripts\python.exe scripts\collect_regulations.py --target 120
.venv\Scripts\python.exe scripts\import_regulations.py --inbox "法规数据\待导入"
```

### 4. 放行法规

新导入的法规处于待复核状态，放行后才会进入检索。

```powershell
.venv\Scripts\python.exe scripts\review_regulations.py --list
.venv\Scripts\python.exe scripts\review_regulations.py --approve-all --note "首批导入"
```

逐条放行用 `--approve <法规ID>`。

### 5. 建立向量索引

```powershell
.venv\Scripts\python.exe scripts\build_vector_index.py
```

需要 13～20 分钟，不要中断。

| 地址 | 用途 |
|---|---|
| <http://localhost:3000> | 系统主界面 |
| <http://localhost:8000/docs> | 接口文档 |

```powershell

.venv\Scripts\python.exe scripts\verify_api.py
```

输出中没有 `[失败]` 行，且结尾为 N/N，即为安装成功。

## 配置项速查表

修改 `.env` 后执行 `docker compose up -d` 生效。

### 应用

| 配置项 | 默认值 | 说明 |
|---|---|---|
| `APP_NAME` | `财税知识引擎` | 界面显示名称 |
| `ENVIRONMENT` | `development` | 对外服务填 `production` |
| `LOG_LEVEL` | `INFO` | 排查问题时填 `DEBUG` |
| `BACKEND_PORT` | `8000` | 后端端口 |
| `FRONTEND_PORT` | `3000` | 前端端口 |

### 数据库与缓存

| 配置项 | 默认值 | 说明 |
|---|---|---|
| `POSTGRES_USER` | `cs_user` | 数据库用户名 |
| `POSTGRES_PASSWORD` | `cs_password` | 数据库口令，需修改 |
| `POSTGRES_DB` | `customer_service` | 数据库名 |
| `POSTGRES_PORT` | `5432` | 数据库端口，不对内网开放时可关闭 |
| `QDRANT_HTTP_PORT` | `6333` | 向量库端口 |
| `REDIS_PORT` | `6379` | 缓存端口 |

### 对象存储

| 配置项 | 默认值 | 说明 |
|---|---|---|
| `S3_ACCESS_KEY` | `cs_s3` | 访问账号，需与 `deploy/seaweedfs/s3.json` 一致 |
| `S3_SECRET_KEY` | `cs_s3_password` | 访问口令，需与 `deploy/seaweedfs/s3.json` 一致 |
| `S3_BUCKET` | `customer-service` | 存储桶名称 |
| `S3_ENDPOINT` | `http://seaweedfs:8333` | 换用云存储时修改此处 |
| `S3_REGION` | `us-east-1` | 换用云存储时修改 |
| `S3_PORT` | `9000` | 存储接口端口 |

### 向量化

| 配置项 | 默认值 | 说明 |
|---|---|---|
| `EMBEDDING_BACKEND` | `stub` | `bge_m3` 为真实模型 |
| `EMBEDDING_MODEL` | `/models/bge-m3` | 模型目录 |
| `EMBEDDING_PORT` | `8001` | 服务端口 |
| `EMBEDDING_USE_FP16` | 空 | 无显卡时保持为空 |
| `HF_HUB_OFFLINE` | `1` | 保持 `1` |

### 模型接口

| 配置项 | 默认值 | 说明 |
|---|---|---|
| `LLM_MODEL` | `deepseek-chat` | 使用的模型 |
| `LLM_BASE_URL` | `https://api.deepseek.com` | 接口地址 |
| `LLM_API_KEY` | 空 | 填入后方可使用该功能 |
| `LLM_FALLBACK_*` | 空 | 备用服务商，可选 |

### 安全

| 配置项 | 默认值 | 说明 |
|---|---|---|
| `JWT_SECRET` | `change-me-in-production` | 登录令牌密钥，需修改 |
| `JWT_EXPIRE_MINUTES` | `1440` | 登录有效期（分钟） |
| `CORS_ORIGINS` | `http://localhost:3000` | 对外服务时改为自己的域名 |

### 管理员与功能开关

| 配置项 | 默认值 | 说明 |
|---|---|---|
| `BOOTSTRAP_ADMIN_USERNAME` | `root_admin` | 管理员账号名 |
| `BOOTSTRAP_ADMIN_PASSWORD` | 空 | 管理员口令，需修改 |
| `FEATURE_PLANNING_ENABLED` | `false` | 是否开放筹划功能 |
| `DOMAIN_PACK_STRICT` | `true` | 对外服务时建议改为 `false` |

## 常用命令

```powershell
docker compose up -d              # 启动
docker compose stop               # 停止，保留数据
docker compose start              # 再次启动
docker compose down -v            # 停止并删除全部数据
docker compose logs -f backend    # 查看后端日志
docker compose ps                 # 查看服务状态
```

### 备份

```powershell
docker compose exec -T postgres pg_dump -U cs_user customer_service > backup_db.sql
Compress-Archive -Path "法规数据" -DestinationPath backup_法规数据.zip -Force
```

数据库用户名不是 `cs_user` 时，替换为实际用户名。

### 升级

```powershell
git pull
docker compose build backend worker frontend
docker compose up -d
docker compose exec -T backend alembic upgrade head
```

## 常见问题

| 现象 | 处理 |
|---|---|
| 提示连不上 Docker | 打开 Docker Desktop，等待图标停止转圈 |
| 拉取镜像报 `no such host` | 重新执行一次，仍失败则重启 Docker Desktop |
| 第一次启动时间很久 | 正常，等待 10～30 分钟 |
| 某个服务一直不是运行状态 | 执行 `docker compose logs <服务名>` 查看报错 |
| 提示端口已被占用 | 修改 `.env` 中对应的 `*_PORT` 端口号 |
| 后端启动失败并提示口令过短 | 将 `BOOTSTRAP_ADMIN_PASSWORD` 改为 12 位以上 |
| 页面能打开但没有数据 | 检查 `CORS_ORIGINS` 是否填写了当前访问地址 |
| 问答提示未检索到条文 | 执行第七步的第 3、4、5 条 |
| 问答结果不准确 | 检查 `EMBEDDING_BACKEND` 是否为 `bge_m3`，并重新执行建立索引 |
| 忘记管理员口令 | 执行 `docker compose exec backend python /app/scripts/reset_admin_password.py` |
