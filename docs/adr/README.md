# 架构决策记录（ADR）

每份 ADR 记录一条已经定下的口径：为什么这么定、放弃了什么、会带来什么后果。
后续若要调整，**另起一份新 ADR**，不改动原文件——这样能保留完整的决策轨迹。
写法见 [变更记录规范](../变更记录规范.md)。
