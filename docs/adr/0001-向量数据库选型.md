# ADR-0001：向量库选用 Qdrant

**状态**: 生效中

## 背景

系统需要语义检索能力，要在若干向量库中选一个。

## 决策

选用 **Qdrant**。

## 备选方案

**pgvector**

- 优点：与 PostgreSQL 集成最简单
- 缺点：大规模性能有限，过滤与聚合能力弱，十万条以上开始吃力
- 未采用：知识库规模增长快，需要生产级性能

**ChromaDB**

- 优点：启动快，Python 原生
- 缺点：生产稳定性一般，无云托管，过滤能力弱
- 未采用：不适合生产部署

## 后果

- 正：REST API 易用，有官方 Python SDK，过滤查询强，可云托管
- 负：比 pgvector 多维护一个独立服务
- 风险：需定期备份 Qdrant 数据目录
