# ADR-0007 引用标识口径与测试集合隔离

- 状态：已采纳（accepted）
- 日期：2026-09-30
- 决策者：项目负责人

## 背景

补采法规到 100 份之后，检索质量验收（`scripts/verify_retrieval.py` 的 B.trace 项）
第一次出现失败：Top-10 引用里有 3 条拿不到文号。追下去发现是两件事：

1. **法律和行政法规本来就没有"发文字号"。** 国家税务总局政策法规库里，
   法律（如《中华人民共和国环境保护税法》）的"发文字号"字段是空的，
   因为法律由**主席令**公布、行政法规由**国务院令**公布，法规本身的编号不是发文字号。
   这不是采集缺陷，是数据源的客观情况。
2. **跑测试会把向量索引删空。** `backend/tests/test_collections_g4.py` 等用例为了
   验证索引写入，会先"清空集合再灌数据"，而测试连的是同一个 Qdrant 实例。
   后果是：跑一次 `pytest`，开发环境里 4924 条真实向量全没了，
   检索看起来正常、其实召回为空——属于会静默出错的严重问题。

两件事都必须定口径，否则检索层会时而"能引用"时而"不能引用"。

## 决策

### 一、引用标识分两类

| 法规类型 | 引用标识 | 例 |
|---|---|---|
| 法律、行政法规 | 有文号用文号；没有则用**法规名称** | 《中华人民共和国增值税法》第十六条 |
| 部门规章、规范性文件 | **必须有文号** | 财税〔2019〕39号 第二条 |

判定落在 `Citation.is_traceable()`：必须同时有条款号和文件标识。
显示用 `Citation.label()` 宽松处理（退回法规名称即可），
判定严格（法律/行政法规之外的必须带文号）。

理由：法律的引用习惯就是写法规名称，"《中华人民共和国增值税法》第十六条"
完全可以定位到条文。而规范性文件不能这么办——同名公告太多
（"国家税务总局关于……的公告"每年几十份），没有文号无法唯一定位。

**不允许为了通过验收而去编造文号。** 系统对"抽不到就标待复核、绝不编造"这条规则不变。

### 二、测试与生产用不同的 Qdrant 集合

集合名加前缀，由环境变量 `QDRANT_COLLECTION_PREFIX` 控制：

- 生产/开发：前缀为空，集合名 `kb_articles` 等
- 自动化测试：`backend/tests/conftest.py` 设前缀 `test_`，集合名 `test_kb_articles` 等

### 三、测试与生产用不同的 Celery 队列

集合隔离只解决了一半。复核接口在放行后会往 Celery 投一个"重建索引"任务，
而测试跑的是同一个 Redis——**测试投出的任务会被真正在跑的后台 worker 领走，
在真实数据上执行**。

这个缺陷在 2026-09-30 真的触发了一次：测试投出的两个 `app.rebuild_index` 任务
被 worker 执行，执行期间 embedding 容器正好在重启，结果是
**先清空了真实索引，再因为向量服务不可用而什么都没写回去**——检索全线返回空。

处理：测试用 15 号 Redis 库（默认 0 号），投出的任务没人消费。

### 四、重建索引前必须先探活

`index_articles` 的顺序必须是：**先调一次 embedding 探活，确认可用再清空旧点**。
失败直接返回 `aborted=embedding_unavailable`，保留原有索引点。

不要把顺序写成"先清空再取条文"——第二步之后一旦出问题，索引就空了。

原则："索引是旧的"只是不新鲜，仍能查；"索引是空的"是全部查不到。
宁可慢一步，也不能清空。

## 备选方案

**A. 给法律补一个"主席令第X号"作为文号。**
否决：需要额外采集来源，且官方库本身不提供；在数据到手之前先按名称引用更稳。

**B. 放宽 B.trace 到"只要标题非空就算可溯源"。**
否决：那等于取消了这条红线。规范性文件必须有文号，这一条不能松。

**C. 测试改用独立的 Qdrant 实例（另一个端口/容器）。**
否决：要改编排与端口映射，成本高于收益。集合前缀能达到同样的隔离效果，
且测试代码不需要改（全部走 `COLLECTIONS` 常量）。

## 后果

- 引用卡片：法律/行政法规显示法规名称 + 条款号；规范性文件显示文号 + 条款号。
- 跑测试不再影响开发库的向量索引。测试会留下 `test_*` 前缀的集合，
  属于预期行为，可随时清理。
- 仍需补的缺口：部门规章（如《中华人民共和国发票管理办法》）应当带
  "国家税务总局令第X号"，当前已入库的这份缺文号，会让它的引用判定为"不可溯源"。
  已记入待办。
