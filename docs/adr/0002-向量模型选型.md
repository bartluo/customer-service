# ADR-0002：向量模型选用 bge-m3（本地离线）

**状态**: 生效中

## 背景

法规文本以中文为主，需要中文语义效果好的向量模型；同时要求法规原文不出内网。

## 决策

选用 **bge-m3**（1024 维稠密 + 稀疏向量），模型文件随部署包提供，
**本地离线加载**，不调用任何外部接口。

## 备选方案

**调用云端 Embedding 接口**

- 优点：不必自备算力
- 未采用：法规原文要出内网，且按量计费

**更小的本地模型**

- 优点：占用低、速度快
- 未采用：中文语义质量不足以支撑专业检索

## 后果

- 正：数据不出内网、无调用费用、中文效果好
- 负：模型约 2.1 GB，常驻内存约 2～3 GB
- 风险：CPU 推理较慢，全量重建索引约 13～20 分钟；更换向量模型后必须重建索引
