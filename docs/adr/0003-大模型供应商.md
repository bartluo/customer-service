# ADR-0003：大模型选用 DeepSeek，并预留备用供应商

**状态**: 生效中

## 背景

事实抽取与答案生成需要大模型，要求中文能力好、成本可控，并且不绑定单一厂商。

## 决策

默认使用 **DeepSeek**（`deepseek-chat`），并在配置中预留备用供应商
（`LLM_FALLBACK_MODEL` / `LLM_FALLBACK_BASE_URL` / `LLM_FALLBACK_API_KEY`），
主供应商不可用时切换。

密钥未配置时，依赖大模型的功能不可用，但不影响检索、计算与验证等链路启动。

## 后果

- 正：中文能力强、成本低；供应商可替换，不绑定单一厂商
- 负：需要管理密钥；备用供应商需另行配置
- 风险：外部服务稳定性需要监控
